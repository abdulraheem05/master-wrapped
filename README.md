**Master Academy Wrapped** is an immersive, high-energy analytics dashboard inspired by Spotify Wrapped. Built for the students of Master Academy, it transforms raw attendance and performance data into a personalized, interactive "Year in Review" experience.

This project showcases a blend of **Full-Stack Engineering** and **Creative Direction**, featuring fluid animations, robust data cleaning logic, and automated social media asset generation.
