## What this is

**Master Academy Wrapped 2025** is a Spotify Wrapped-style analytics platform built for the students of Master Academy.

The project takes real-world, messy academic data such as student attendance records, class participation, subject activity, lecturer interactions, and purchase/history-related records, then transforms them into a clean, personalized, interactive year-in-review experience for each student.

The main goal of this project was to turn raw operational data into something students would actually enjoy viewing and sharing. Instead of showing boring tables or reports, the platform presents each student’s yearly learning journey through animated cards, visual statistics, personalized insights, and social-media-friendly summary screens.

Behind the scenes, the data had to be queried, cleaned, structured, and prepared using SQL and custom data handling logic before being displayed in the frontend. Since the original records came from real academy operations, the data was not perfectly formatted, so a major part of the project involved cleaning inconsistent records and converting them into meaningful visual insights.

This project showcases a mix of **full-stack engineering, data cleaning, SQL querying, frontend animation, creative direction, and real-world product thinking**.
